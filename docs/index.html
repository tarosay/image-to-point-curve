画像 → Point Curve 変換

画像から輪郭を抽出し、DesignSpark Mechanical で読み込める Point Curve 形式の TXT に変換します。寸法は mm。画像はサーバーへ送信されず、ブラウザ内だけで処理します。

方式輪郭数点数重複区間の長さ
重複区間の長さは、別の色の輪郭の線から 1.2 px（処理解像度）以内を通る部分の長さを、出力寸法の mm に換算した目安です。同じ色の輪郭どうし（細い線の表と裏など）は数えません。
初期値は True。False にすると DSM で直線や角も滑らかに補間されることがあります。

出力サイズ

直径mm
抽出したすべての輪郭の点を囲む最小の円が、この直径になるように拡大縮小します。座標原点は円の中心、Y軸は上向きです。Polyline=False（スプライン補間）では、曲線が円からわずかにはみ出す可能性があります。
幅mm
高さmm
画像全体（余白を含む）の縦横比を維持します。座標原点は画像の左下、Y軸は上向きです。

出力する色
チェックした色の領域の輪郭を出力します。画像の縁に最も多い色を背景とみなし、初期状態で外しています。

重複の削減

隣り合う2色の境界は、従来の方式では両方の色から1回ずつ出力されて重なります。重複を減らす方式では、すべての境界線が少なくとも1回出力される範囲で、出力する領域を選んで重なりを減らします。出力はすべて閉曲線です。重複が完全になくならない場合があります。
2色の境目のにじみが別の色として抽出された、幅2画素以下の細い領域を、隣の色に塗り替えます。両側の境界の位置がそろい、ずれた重複を防ぎます。隣の色の中間でない色の細い線は吸収しません。

輪郭の細かさ

1.0 px
小さいほど元の形に忠実で点数が増え、大きいほど点数が減ります。
2
画素のギザギザをならす回数です。大きくすると角が丸くなります。
画像をこの大きさに縮小してから輪郭を抽出します（拡大はしません）。許容誤差などの px はこの解像度での値です。

ノイズ除去

20 px²
これより小さい領域（点状のゴミ・小さな穴）を除去します。重複を減らす方式では、隣の色に塗り替えて吸収します。
0
周囲 3×3 画素の多数決で境界を整える回数です。細い線は消えることがあります。
出力形式：先頭行 Polyline=True、各点 0 X Y（mm）。複数の輪郭は空行で区切り、各閉曲線の最後に始点を再出力します。DXF は R12 形式で、各輪郭を閉じたポリラインとして出力します（単位 mm、色ごとに画層を分けます）。
