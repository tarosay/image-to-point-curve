画像 → Point Curve 変換

画像から輪郭を抽出し、DesignSpark Mechanical で読み込める Point Curve 形式の TXT に変換します。寸法は mm。画像はサーバーへ送信されず、ブラウザ内だけで処理します。

またはタップしてファイルを選択（PNG / JPEG / WebP）
画像を選択してください。
初期値は True。False にすると DSM で直線や角も滑らかに補間されることがあります。

出力サイズ

直径mm
抽出したすべての輪郭の点を囲む最小の円が、この直径になるように拡大縮小します。座標原点は円の中心、Y軸は上向きです。Polyline=False（スプライン補間）では、曲線が円からわずかにはみ出す可能性があります。
幅mm
高さmm
画像全体（余白を含む）の縦横比を維持します。座標原点は画像の左下、Y軸は上向きです。

抽出方法

画像を読み込むと自動で選びます。必要なら切り替えてください。
128
8
写真など色数の多い画像は、この色数まで減らして近似します。

値を大きくすると、近い色を同じ色としてまとめます。
出力する色
チェックした色の領域の輪郭を出力します。画像の縁に最も多い色を背景とみなし、初期状態で外しています。

輪郭の細かさ

1.0 px
小さいほど元の形に忠実で点数が増え、大きいほど点数が減ります。
2
画素のギザギザをならす回数です。大きくすると角が丸くなります。
画像をこの大きさに縮小してから輪郭を抽出します（拡大はしません）。許容誤差などの px はこの解像度での値です。

ノイズ除去

20 px²
これより小さい輪郭（点状のゴミ・小さな穴）を除去します。
0
周囲 3×3 画素の多数決で境界を整える回数です。細い線は消えることがあります。
出力形式：先頭行 Polyline=True、各点 0 X Y（mm）。複数の輪郭は空行で区切り、各閉曲線の最後に始点を再出力します。
