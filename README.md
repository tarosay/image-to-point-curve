# image-to-point-curve
画像の輪郭を抽出し、Point Curve形式のテキストファイルに変換するWebツール。白黒・カラー画像に対応。 / A web tool that extracts contours from monochrome and color images and converts them into Point Curve text files.

## 公開ページ

https://tarosay.github.io/image-to-point-curve/

画像の処理はすべてブラウザ内で行います。画像がサーバーへ送信されることはありません。スマートフォンでも使えます。

## 使い方

1. 画像（PNG / JPEG / WebP）を画面上部の枠にドラッグ＆ドロップするか、枠をタップして選択します。
2. 画像の種類（白黒・線画／カラー）が自動で選ばれ、抽出した輪郭がプレビューに表示されます。
3. 必要に応じて右側（スマートフォンでは下側）のパラメータを調整します。
4. 「point curve (.txt) をダウンロード」を押して TXT を保存します。
5. DesignSpark Mechanical で TXT を Point Curve として読み込みます。

### 調整できる項目

| 項目 | 内容 |
| :--- | :--- |
| 読み込み方式（Polyline） | True：折れ線（初期値）／False：スプライン補間 |
| サイズの決め方 | **円に収める**（初期値）：すべての輪郭の点を囲む最小の円の直径を指定（初期値 78.5 mm）。原点は円の中心<br>**画像全体の幅・高さを指定**：余白を含む画像全体の縦横比を維持。原点は画像の左下 |
| 画像の種類 | 白黒・線画：明るさで二値化（しきい値は自動または手動、反転も可）<br>カラー：最大色数と色の判定許容差で色をまとめ、出力する色をチェックで選択（画像の縁に最も多い色を背景として初期状態で除外） |
| 簡略化の許容誤差 | 小さいほど元の形に忠実で点数が増え、大きいほど点数が減る |
| なめらかさ | 画素のギザギザをならす回数。大きくすると角が丸くなる |
| 処理解像度 | 画像をこの長辺サイズに縮小してから輪郭を抽出（拡大はしない） |
| 除去する最小面積 | これより小さい輪郭（点状のゴミ・小さな穴）を除去 |
| 細かな凹凸の除去 | 3×3 画素の多数決で境界を整える回数。細い線は消えることがある |

座標はいずれも mm 単位、Y 軸は上向きです。

## 出力形式

```
Polyline=True
0 10.0000 20.0000
0 15.0000 25.0000
0 20.0000 20.0000
0 10.0000 20.0000

0 30.0000 40.0000
...
```

- 各行は `0 X Y`（mm、小数4桁）
- 外周・内側の穴を含め、複数の閉曲線を空行で区切って出力
- 各閉曲線の最後に始点を再出力
- 改行コードは CRLF
